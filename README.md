# <img src="https://raw.githubusercontent.com/devicons/devicon/master/icons/python/python-original.svg" alt="Python Logo" width="25" height="25" style="vertical-align: middle;" /> Fundamentals of Python 

This repository serves as a practical, structured reference for learning core Python concepts. It covers fundamental programming topics ranging from variable declarations and operators to data structures, loops, and functions.

---

## Topics Covered

### Part 1: Output, Variable, Type, Input, Concatenation & Comment
* Standard output formatting and message printing
* Dynamic variable allocation and memory binding
* Data type inspection
* Standard input handling
* String concatenation via operators and argument separation
* Code documentation using single-line and multi-line comments

### Part 2: Type Casting & Conversion, String Operations & Reserved Keywords
* Implicit type conversion (automatic promotion) and explicit type casting (manual conversion)
* Built-in string methods for case transformation, searching, and replacing substrings
* Substring existence checks using membership operators
* Syntax restrictions regarding reserved language keywords

### Part 3: Arithmetic, Assignment, Comparison, Logical & Conditional Operators with Operator Precedence
* Arithmetic operations (addition, subtraction, multiplication, division, modulus, exponentiation)
* Compound assignment operations
* Precedence rules controlling execution order in complex mathematical expressions
* Relational/comparison operations evaluating boolean conditions
* Boolean logic evaluation (conjunction, disjunction, negation)
* Conditional branching logic using control structures

### Part 4: Range, While Loop, For Loop, Break & Continue
* Sequence generation using start, stop, and step arguments
* Indefinite condition-based iteration
* Definite sequence iteration
* Early loop termination and loop pass-through controls

### Part 5: List, Index, Slice, Tuple, Set & Dictionary
* **Lists:** Mutable ordered collections, zero-based indexing, element slicing, and list mutation methods
* **Tuples:** Immutable ordered sequences, index lookups, and immutability properties
* **Sets:** Unordered collections of unique elements and set-based iterations
* **Dictionaries:** Key-value mappings, safe value fetching, key/value extraction, and key-value pair iteration

### Part 6: Function, In-built & Module Functions
* Function definition syntax, parameters, arguments, and return values
* Standard built-in function execution for common utilities (length, mathematical bounds, sorting, types)
* Standard library module imports, namespace usage, and function invocation from internal libraries
